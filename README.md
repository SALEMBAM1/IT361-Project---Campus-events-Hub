# IT361-Project---Campus-events-Hub
Campus Events Hup - Dynamic Web

## Project Overview
Campus Events Hub is a dynamic web application designed for a fictional university club/department. It allows university students to discover upcoming campus events (workshops, seminars, competitions) and register for them online.

##Technologies Used
- **Frontend:** HTML5, CSS3 (Shared external stylesheet with responsive layout)
- **Backend:** PHP (Template, server-side from validation, dynamic page routing)
- **Data Storage:** CSV file (`registrations.csv`) & PHP Array (`events_data.php`)

## How to Run 
1. Install and start **XAMPP**.
2. Place the project folder inside `C:/xampp/htdocs/`.
3. Start the **Apache** service from the XAMPP Control Panel.
4. Open your browser and navigate to: `http://localhost/IT361_php/`
